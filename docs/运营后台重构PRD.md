# 叮当支付运营后台 · 整体重构 PRD

版本 v2.0 · 2026-11-14 · 基于 XGD 开户管理页（卢森堡 PI 牌照 Z00000026，CSSF 监管）现有 UI 迭代
合规基准：卢森堡 CSSF AML/CFT（Loi du 12 novembre 2004 修订版）、EU AMLD6、FATF RBA、EU 制裁条例、OFAC/UN 名单义务、资料留存 ≥5 年

---

## 1. 重构背景、现存问题总结、业务目标

### 1.1 现存问题（本次必须全部解决）

| # | 问题 | 影响 |
|---|---|---|
| P1 | 页面仅列表展示，业务操作功能缺失 | 审核、管控、上报均无法闭环 |
| P2 | 模块间数据不联动 | 开户不触发筛查/评分/EDD；结果不回写台账；告警无法关联开户单 |
| P3 | 角色权限混乱、边界模糊 | 越权操作风险，违背 SoD（职责分离）原则 |
| P4 | BO 穿透、EDD 只有入口无闭环 | UBO 核验义务（卢森堡法第 1(7) 条）无法履行 |
| P5 | 缺审计留痕、审批流、管控工单、STR、定期复审 | 无法满足 CSSF 监管检查 |
| P6 | 缺统一客户 360 视图 | 开户/风控/交易数据分散，口径不一致 |

### 1.2 业务目标

1. 三大域（开户管理 / 风控合规 / 平台运营）统一客户数据源，单一事实源（SSOT）；
2. 全链路自动→人工双轨：系统自动筛查评分分流，最终处置必须人工审批；
3. 六角色权责隔离，权限矩阵可视化配置；
4. 监管就绪：任意客户 5 分钟导出全套 KYC+EDD+筛查+审核档案包。

## 4. 业务流程图

### 4.1 完整开户全流程
```
客户提交开户
 → [自动] 材料完整性校验（缺件→自动退回补件并通知客户经理）
 → [自动] 名单筛查：EU/OFAC/UN/PEP/自定义库（个人查本人；商业查企业+董事+全部UBO）
 → [自动] 风险评分（因子权重取自合规配置中心）
 → 自动分流：
    低风险 → 常规审核队列
    中/高风险 → 自动创建开户 EDD 工单 → EDD 结论回流
    命中制裁/PEP → 自动生成风控告警 + 开户单挂起
 → 人工审核（三选一，全部留痕）：
    通过 → 自动开立账户 → 自动创建客户风险台账档案（客户360）
    退回补件 → 推送客户经理后台待办（脱敏）→ 客户补件 → 回待审核
    拒绝 → 拒户原因（模板库）→ 双人审批 → 写入全局黑名单 → 禁止重复提交
```

### 4.2 开户-风控联动流程
```
开户模块                          风控合规模块
提交/变更 ──触发──▶ 筛查+评分+分流
BO 新增/变更 ─────▶ 对单 BO 重筛并留痕
命中/高风险 ──────▶ 自动生成告警（关联开户单号）
                    EDD 结论 ──回写──▶ 开户状态（通过/持续监控/拒绝）
开户通过 ─────────▶ 自动建档（台账+初始等级）
开户拒绝 ─────────▶ 写入全局黑名单
                    风险等级调整 ──回写──▶ 开户档案+客户台账
```

### 4.3 告警-案件-管控-STR 闭环
```
告警（自动规则产生）→ 分配（主管）→ 调查（专员，证据归档）
 → 结论分支：
    误报 → 放行（留痕）
    属实 → 转案件 → 处置选择：
       ├─ 账户管控（主管发起 → 合规负责人终审 → 生效；解除同流程）
       ├─ 持续监控（加强复审频率）
       └─ STR 上报（草稿 → 合规负责人签发 → 监管报送 → 归档）
 → 每一步写入审计日志 + 回写客户风险台账
```

## 5. 核心页面 PRD

### 5.1 商业开户总看板（基于现有 XGD 页迭代，保留原结构）
- **用途**：商业开户大盘。
- **保留**：六张统计卡（材料收集中/已递交 XGD/XGD 审核中/要求补件/开户成功/开户失败）。
- **新增**：风险等级分布条（低/中/高/极高）、EDD 待处理工单数、本周拒绝率、平均审核时长。
- **筛选**：风险等级、国家、渠道、客户经理、时间范围。
- **操作**：快捷入口（列表/EDD 工单/复审台账/驳回模板）。
- **权限**：全角色可见；审计只读。

### 5.2 商业开户申请列表（保留原列表字段并增强）
- **保留字段**：单号/公司、注册地/行业、材料进度、当前阶段、负责人、更新时间、操作。
- **新增字段**：风险等级、筛查命中标记（企业/董事/BO 三列）、客户经理归属。
- **筛选**：阶段、风险等级、国家、行业、命中标记、客户经理、提交时间段。
- **行操作**：查看详情、退回补件、转 EDD、分配负责人、导出单户资料。
- **批量**：仅低风险+无命中可批量；批量动作二次确认+留痕。
- **权限**：分配=主管+；转 EDD=专员+；导出=主管/负责人/审计。

### 5.3 商业开户详情 & 综合审核页
- **Tab 分区**：主体信息 / 注册文件 / 董事清单 / BO 穿透（跳 5.4）/ 业务与上下游 / 筛查结果（企业+董事+每名 BO 独立卡片）/ 风险评分 / EDD 材料区 / 流转记录 / 审核操作区。
- **审核操作**：通过开户、退回补件（选缺件+说明→推送客户经理后台）、发起 EDD、拒绝开户（原因库+双人审批）、移交风控。
- **附加**：内部备注（客户与客户经理不可见）、佐证附件上传、站内通知。
- **权限**：按第 3 节矩阵；高风险通过/拒绝需合规负责人终审。

### 5.4 BO 受益所有人穿透抽屉（右侧抽屉，非弹窗）
- **结构**：树形穿透图，每层标注：持股比例、控制权类型（直接/间接链条/投票权/股东协议/高管兜底）、PEP 属性、制裁命中、证件类型、居住地址。
- **功能**：新增/编辑受益人；**任何 BO 变更自动重新触发该 BO 筛查并生成版本快照**（修改前后对比留痕）；单 BO 追加筛查按钮。
- **脱敏差异**：运营端可见全量；客户经理端仅显示 BO 姓名与待补材料项，隐藏命中详情与评分。

### 5.5 开户 EDD 强化尽调工单
- **触发**：高风险国家/行业、PEP·制裁疑似、大额预估流水、BO 结构不透明（自动）+ 人工发起。
- **字段**：工单号、关联开户单、触发原因、材料清单（贸易合同/发票样本/上下游证明/资金来源说明/EDD 问卷）、截止日、审批流节点、结论。
- **流转**：创建 → 材料收集中（推送客户经理补充）→ 初审（合规审核员）→ 复核（风控主管）→（极高风险）终审（合规负责人）→ 结论：通过 / 持续监控 / 拒绝 → **回写开户单据状态**。
- **输出**：EDD 报告 PDF（含问卷、材料清单、审批链、结论）。
- **权限**：初审=审核员；复核=主管；终审=负责人；审计只读。

### 5.6 客户风险台账（客户 360 统一视图，唯一数据源）
- **区块**：基础信息、开户信息（渠道/单号/账户）、BO 信息、当前风险等级（变更历史）、筛查历史、EDD 记录、交易风险标签、账户管控历史、复审到期。
- **说明**：开户/风控/运营三模块读写同一数据源；任何模块修改等级自动全端同步。
- **操作**：调级（主管发起→负责人确认）、导出台账、跳转开户档案。
- **权限**：查看=全角色；调级=主管/负责人。

### 5.7 名单筛查管理
- **Tab**：筛查记录（实时+定时批量）/ 命中复核（误报标记、确认命中→自动生成告警）/ 名单库（EU/OFAC/UN/PEP/自定义，启停与版本日期）。
- **权限**：误报标记=专员/审核员/主管；名单库=负责人/超管。

### 5.8 交易告警中心
- **字段**：告警号、来源（交易/开户联动）、客户、命中规则、金额、等级、状态、负责人。
- **筛选**：状态、等级、来源、规则。
- **操作**：分配、开始调查、结论（放行/转案件/转管控/生成 STR 草稿）。
- **状态机**：新告警 → 调查中 → 待审批 → 已结论。

### 5.9 风控案件 & 工单管理
- **字段**：案件号、关联告警/开户单、类型、证据附件、流转历史、处理人、SLA、结论。
- **操作**：认领、分配、证据归档、调查结论（放行/管控/STR）、升级。

### 5.10 账户管控中心
- **类型**：限制入金、禁止出金、暂停账户、资金冻结/解冻。
- **审批流**：主管发起 → 合规负责人终审 → 生效；解除同流程；理由必填永久留痕。
- **红线**：禁止自动永久冻结；系统自动规则仅产生告警。
- **权限**：发起=主管/负责人；终审=负责人。

### 5.11 STR 可疑交易上报
- **状态机**：草稿 → 已签发上报（监管报送，记录报送回执）→ 已归档。
- **权限**：起草=专员/主管/负责人；**签发仅合规负责人**。

### 5.12 合规审计日志中心
- **范围**：开户、风控、管控、审批、配置、登录全部操作；记录操作人/角色/对象/修改前后值/IP。
- **特性**：只增不删；多维检索（客户/人员/类型/时间）；CSV/PDF 导出。

### 5.13 风控合规配置中心
- **内容**：评分因子权重（合计=100）、等级阈值、国家风险库、行业风险库、EDD 触发规则、复审周期、告警阈值、自动规则开关。
- **权限**：负责人/超管；变更全部留痕（修改前后对比）。

### 5.14 平台运营总模块（模块3）
- **运营总看板**：开户量、账户数、渠道统计、待办大盘。
- **客户主体总览**：个人+商业统一列表，跳转开户档案/风险台账。
- **客户经理管理**：账号维护、客户归属分配；归属变更自动同步开户列表与台账。
- **角色权限配置中心**：第 3 节矩阵的可视化配置（仅超管）。
- **监管数据包导出**：单户一键导出全套 KYC+EDD+筛查+审核档案包。

## 9. 非功能与合规约束

1. 所有业务操作、附件、审核意见、修改前后对比必须写审计日志，**禁止物理删除**，留存 ≥5 年（CSSF 要求）。
2. 区分自动动作（筛查/评分/分流/告警）与人工审批动作；拒户、管控、冻结、STR 签发必须人工审批流转。
3. 单户监管档案包一键导出（KYC+EDD+筛查+审核+管控全套）。
4. 客户经理端与运营端数据双向同步，敏感风控字段对客户经理脱敏。
5. 权限矩阵可视化配置，变更留痕。
6. 页面保留现有 XGD 管理页 UI 结构（统计卡+列表）迭代，不推翻重设计。
