# 叮当支付运营后台 · 开户管理模块 产品方案（PRD）

版本 v1.0 · 2026-11-14
合规基准：EMI 牌照义务 / EU AMLD6 / FATF 建议 / 意大利 UIF 报送要求

---

## 一、模块总 PRD

### 1.1 定位与边界
开户管理是 dingdangpay 平台的准入关口，承担 KYC/KYB 受理、风险准入决策与账户开立的完整闭环。本模块与「风控与合规模块」强联动：开户提交即触发自动风险评分与名单筛查，中高风险自动流转 EDD 工单；审核结论同步商户/客户风险台账。

### 1.2 业务定义区分

| 维度 | 个人开户 | 商业（企业）开户 |
|---|---|---|
| 客户主体 | 自然人 | 有限公司/贸易主体/跨境电商/奢侈品商家 |
| 产品 | 个人全球支付账户（跨境汇款、换汇） | 企业多币种账户 + 收单 |
| KYC 深度 | 证件 + 地址证明 + 资金用途 | 企业信息 + 董事 + BO 多层穿透 + 业务背景 + 上下游 |
| BO 穿透 | 不涉及 | 强制，穿透至最终自然人（UBO，持股 ≥25% 或控制权） |
| EDD | 仅命中高风险场景触发 | 中高风险强制 EDD |

### 1.3 统一准入流程（两线共用主干）

```
客户前端提交开户申请
  ↓
[自动] 材料完整性校验（缺件自动退回补材料）
  ↓
[自动] 名单筛查：OFAC / EU / UN / PEP / 自定义黑名单（个人查本人；商业查企业+董事+全部BO）
  ↓
[自动] 风险评分（注册地/行业/交易规模/BO结构/资金模式，权重取自风控评分配置）
  ↓
自动分流：
  ├─ 低风险（0–30）→ 常规审核队列（运营审核员）
  ├─ 中风险（31–55）→ 常规审核 + 合规专员复核
  └─ 高/极高（56–100）→ 自动创建 EDD 工单 → EDD 结论后回到审核
  ↓
人工审核（三选一，均留痕）：
  ├─ 通过 → 自动开立账户（分配 IBAN/账号）→ 客户档案建档 → 同步风险台账
  ├─ 退回补材料 → 站内通知客户 → 客户补件 → 回到待初审
  └─ 拒绝 → 拒户理由（模板库选择+自由补充）→ 写入黑名单库 → 禁止重复提交
```

### 1.4 业务流程图 · 个人开户
```
草稿（客户未提交）
 → 提交 → 待初审 [自动筛查+评分]
   ├─ 筛查/评分异常 → EDD复核中 → 回待初审
   ├─ 材料不全 → 待补材料 → 客户补件 → 回待初审
   ├─ 通过 → 审核通过（自动开户、建档）
   └─ 拒绝 → 已拒绝（拒户理由留痕、入黑名单）
审核通过 → 年度复审 → 复审中 → 通过/限制账户
```

### 1.5 业务流程图 · 商业开户 + BO 穿透 EDD
```
草稿 → 提交 → 待初审 [企业+董事+全部BO 分别筛查，整体评分]
  ├─ 任一主体命中 → 生成风控告警（同步告警中心）
  ├─ 高/极高风险 → EDD强化尽调中
  │     ├─ 触发场景：高风险国家 / 高风险行业 / PEP·制裁疑似 / 大额预估流水
  │     ├─ 收集：贸易合同、发票样本、上下游合作证明、资金来源说明
  │     ├─ BO 穿透核验：多层持股至 UBO，支持对单个 BO 追加筛查
  │     └─ EDD 结论 → 回待初审
  ├─ 待补材料 ⇄ 待初审
  ├─ 通过 → 审核通过（开户+建档+风险台账同步）
  └─ 拒绝 → 已拒绝（高风险拒户需合规负责人批准）
```

## 二、菜单结构与页面清单

### 一级菜单 1：个人开户管理

#### P1 个人开户总看板
- **指标卡**：待初审 / 待补充材料 / EDD 复核中 / 审核通过（本月）/ 已拒绝（本月）/ 复审到期（30 天内）
- **图表**：近 30 天提交量趋势、通过率/拒绝率、风险等级分布、来源国家分布
- **筛选**：风险等级、国家、渠道、时间范围
- **快捷操作**：待办队列直达、批量处理入口、复审到期清单入口

#### P2 个人开户列表
- **字段**：开户单号、客户姓名、注册国家、提交时间、当前状态、风险等级、筛查命中标记（无/疑似/命中）、客户经理归属、账户是否开立
- **筛选**：状态、风险等级、国家、提交时间段、客户经理
- **行操作**：查看详情（右抽屉）、退回补材料、转 EDD、标记复审、导出资料
- **批量**：勾选 → 进入批量处理页

#### P3 个人开户详情 & 审核页（右侧抽屉 + 全页两种形态）
- **分区**：客户基础信息 / 证件材料 / 地址证明 / 资金用途说明 / 筛查结果卡片（本人）/ 风险评分卡片（各因子得分）/ 历史流转记录 / 审核操作区
- **操作按钮**：通过开户、退回补充材料（选择缺件项+说明）、拒绝开户（拒户模板+理由）、移交风控复核
- **附加能力**：内部备注、内部佐证附件上传（客户不可见）、站内通知客户
- **留痕**：每次状态变化、备注、附件写入审计日志

#### P4 个人开户批量处理
- **用途**：同质化低风险件批量提效
- **功能**：按筛选圈选（仅允许低风险+无命中+材料齐全）→ 批量通过/批量退回补材料；批量动作二次确认 + 全量留痕；高风险件禁止批量，必须逐单

#### P5 个人开户驳回模板配置
- 话术模板库：模板名、适用场景（证件不清/地址证明失效/资金用途不明/名单命中等）、话术正文（多语言）、启用状态、最近修改人/时间
- 操作：新增、编辑、启停；删除不允许（仅停用，留痕）

#### P6 个人开户复审台账
- **字段**：客户、开户日期、最近复审日期、下次复审到期日、复审周期、当前状态、历史复审记录数
- **功能**：到期自动提醒（T-7）、复审记录归档、复审不通过 → 提交账户管控建议（仅入金/暂停）

### 一级菜单 2：商业开户管理

#### B1 商业开户总看板
- 同个人看板指标，另增：EDD 处理中工单数、BO 待核实数、高风险行业分布、平均审核时长

#### B2 商业开户列表
- **字段**：开户单号、公司名、注册国家、行业、提交时间、当前状态、风险等级、筛查命中（企业/董事/BO 分列标记）、客户经理、账户是否开立、EDD 工单号（如有）
- **筛选**：状态、风险等级、国家、行业、提交时间、客户经理
- **行操作**：查看详情、退回补材料、发起 EDD、标记复审、导出资料

#### B3 商业开户详情 & 审核页
- **分区**：企业主体信息 / 注册文件 / 营业范围 / 董事清单 / BO 穿透树 / 业务模式 / 预计交易规模 / 上下游简述 / 筛查结果（企业、每名董事、每名 BO 独立卡片）/ 风险评分 / EDD 问卷与材料区 / 历史工单记录
- **审核操作**：通过开户、退回补材料、发起 EDD、拒绝开户（高风险拒户需合规负责人二审）、移交风控
- **BO 操作**：对单个 BO 追加名单筛查、标注 PEP 属性

#### B4 BO 穿透弹窗（商业专属）
- 树形结构：每层标注持股比例、控制权类型（股权/投票权/其他）、是否 PEP、是否制裁命中、证件类型、地址
- 支持新增/编辑受益人；**任何 BO 变更自动重新触发该 BO 名单筛查并留痕**

#### B5 商业 EDD 开户工单
- **触发场景**：高风险国家 / 高风险行业 / PEP·制裁疑似命中 / 大额预估流水
- **材料收集**：贸易合同、发票样本、上下游合作证明、资金来源说明、EDD 问卷
- **流转**：创建（自动/手动）→ 材料收集中 → 审核中 → 通过/驳回 → 回开户审核流；与风控模块 EDD 工单同库同步

#### B6 商业开户批量处理
- 同个人批量规则，额外限制：含 BO 待核实或任一筛查疑似命中的件禁止批量

#### B7 商业开户拒户原因库
- 结构化拒户原因：一级分类（名单命中/资料造假/业务不符/风险超限/监管禁止）+ 二级原因 + 对客话术 + 是否入黑名单（默认入）+ 监管报送标记
- 拒绝动作必须选择原因库条目，可附自由说明

#### B8 商业开户复审台账
- 同个人复审台账，复审周期按风险等级映射（低 12 月/中 6 月/高 3 月/极高 1 月，取自合规配置中心）

#### C1 配置页（开户管理组内）
- 驳回话术模板库（个人/商业分 Tab）
- 开户准入黑名单（命中禁止重复提交）
- 国家风险映射、行业风险映射（与风控合规模块同源只读引用，修改需跳转合规配置中心）
- 自动规则开关：自动筛查、自动评分、自动分流 EDD、到期复审提醒

**个人开户**：草稿 → 待初审 → 待补材料 →（回待初审）→ EDD复核中 →（回待初审）→ 审核通过 → 复审中；终态旁路：已拒绝

## 五、联动规则清单（与风控合规模块）

| # | 触发 | 联动 |
|---|---|---|
| L1 | 开户审核通过 | 客户管理自动生成主体档案，风险等级同步商户风险台账 |
| L2 | 筛查命中制裁/高风险 | 自动生成风控告警（告警中心），开户单挂起 |
| L3 | 高/极高风险评分 | 自动创建 EDD 工单（与风控 EDD 同库，双向可见） |
| L4 | 拒绝开户 | 记录自动写入开户准入黑名单库，同证件/同名主体禁止重复提交 |
| L5 | BO 新增/变更 | 自动对该 BO 重新筛查并留痕 |
| L6 | 复审不通过 | 推送账户管控中心，生成管控建议（仅入金/暂停） |
| L7 | 客户经理字段 | 与客户经理管理模块同源，支持归属筛选与业绩归属 |

## 六、与风控模块对齐的依赖清单

1. **评分模型**：直接引用风控「评分配置」的因子与阈值，不另建一套
2. **名单库**：筛查共用 OFAC/UN/EU/PEP/自定义名单库，版本同步
3. **EDD 工单**：开户 EDD 与风控 EDD 同数据模型（材料清单、问卷、结论、留痕）
4. **风险等级字典**：低/中/高/极高 四级定义与配色一致
5. **审计日志**：开户操作与风控操作写入同一审计流，可按商户聚合
6. **账户管控**：复审不通过走账户管控中心审批流，不在开户模块直接限制

## 七、非功能要求

1. 所有附件、审核意见、操作日志不可删除，留存 ≥ 5 年
2. 单户 PDF 档案包导出：全套 KYC 材料 + 筛查报告 + 评分卡 + 审核记录
3. 自动动作（筛查/评分/分流）与人工审批动作严格区分展示与留痕；拒绝、EDD 结论必须人工
4. 页面风格统一 B 端后台：列表页左侧筛选区、右侧抽屉详情
5. 预留第三方对接字段：KYC 核验（证件真伪/活体）、名单筛查 API、工商数据核验 API

## 八、待业务确认项

1. 个人开户是否开放欧盟以外居民（影响国家风险映射默认值）
2. BO 穿透的持股阈值确认（建议 25%，AMLD 基准；部分辖区 10%）
3. 拒户黑名单的申诉通道与解除流程归属（客服 or 合规）
4. 复审不通过时的宽限期与客户通知时点
5. 批量通过的单日上限与二次确认机制细节
6. 第三方 KYC/筛查供应商选型与字段映射验收标准
