## 1. 模块总 PRD

### 1.1 系统背景
dingdangpay 是面向 B 端企业商户的全球支付平台（SEPA / SWIFT / 跨境收付款 / 多币种账户）。客户均为有限公司主体（奢侈品贸易、电商、贸易公司等）。平台存在 EDD 调查、账户限制、资金冻结、交易拦截、可疑交易上报（STR）、监管审计调取等真实场景。

### 1.2 目标用户
| 角色 | 职责 |
|---|---|
| 风控专员 | 告警处理、案件调查、EDD 材料审核、筛查复核 |
| 合规审核员 | KYC 档案审核、EDD 结论初审、误报标记 |
| 风控主管 | 管控审批、工单分配、规则配置、团队复核 |
| 合规负责人 | STR 签发、极高风险终审、监管对接、合规配置 |
| 审计岗 | 只读查阅 + 审计包导出 |
| 超级管理员 | 全部权限 |

### 1.3 业务流程图

**商户入网风控流程**
```
提交 KYB 开户 → 基础资料完整性校验 → 名单筛查（制裁/PEP/负面/自定义）
→ 自动风险评分（注册地/行业/规模/BO 结构/资金模式）
→ 低风险：简化尽调 SDD → 直接开通
→ 中风险：标准尽调 CDD → 合规审核员复核 → 开通
→ 高风险/极高：强制 EDD 强化尽调工单 → 材料收集 → 审核结论
   → 通过：开通（极高风险默认仅入金）
   → 驳回：拒绝入网（留痕）
```

**持续监控流程**
```
商户信息变更 / BO 变更 / 交易行为偏离 / 高风险地域交易
→ 自动规则引擎触发告警（R-01 ~ R-15）
→ 风控专员调查 → 必要时发起复审或 EDD
→ 风险等级动态重评 → 更新复审计划
```

**告警工单处理流程**
```
告警生成（自动）→ 分配（风控主管）→ 调查取证（风控专员：流水/合同/物流）
→ 结论：放行（误报）/ 加强监控 / 转账户管控（审批流）/ 生成 STR 草稿
→ 所有步骤写入审计日志
```

**账户管控流程**
```
发起管控申请（类型：仅入金/禁止出金/暂停账户/冻结资金 + 理由）
→ 风控主管审批 → 合规负责人批准 → 生效
→ 解除同样需审批 + 理由留痕
→ 禁止自动永久冻结；自动规则不直接管控
```

## 2. 菜单页面清单（全部已实现）

### 2.1 风控总览 risk.html
- **用途**：风险大盘。
- **字段/KPI**：在管商户数、待处理告警、调查中案件、高风险商户（含极高）、名单待复核、STR 本年上报。
- **区块**：最新告警表、商户风险分布（低/中/高/极高占比条）、管控中商户列表。
- **筛选**：无（展示页）。**操作**：跳转告警中心/管控中心。
- **权限**：全角色可见（审计岗只读）。

### 2.2 商户 KYC 档案 risk-kyc.html
- **用途**：企业主体全量档案 + BO 多层穿透。
- **字段**：商户名/编号/注册号/VAT/注册地/行业/上下游/证件材料/BO 树（持股%、层级、最终自然人）/KYC 状态/风险评分/复审到期。
- **筛选**：搜索（table-kit 内置）、查看全部。
- **操作**：档案弹窗、KYC 状态流转（已通过/复审待办/EDD 进行中/暂停入网）。
- **状态流转**：待提交 → 审核中 → 已通过 ⇄ 复审待办 ⇄ EDD 进行中 → 暂停入网。
- **权限**：`kyc_edit` = 合规审核员/风控主管/合规负责人/管理员。

### 2.3 风险评分配置 risk-score.html
- **用途**：评分因子权重配置 + 等级阈值映射。
- **字段**：6 因子（注册地 20 / 行业 15 / 交易规模 15 / PEP·制裁 20 / BO 透明度 15 / 资金模式 15），权重合计须 = 100；阈值表（0–30 低 / 31–55 中 / 56–75 高 / 76–100 极高）。
- **操作**：滑块调权重、保存配置、按新权重重算商户评分。
- **权限**：`score_config` = 风控主管/合规负责人/管理员；其余可见不可改。

### 2.4 EDD 强化尽调工单 risk-edd.html
- **用途**：高风险商户强化尽调。
- **字段**：工单号/商户/触发原因/材料清单进度（资金来源、贸易合同、发票、物流单据、BO 穿透证明）/EDD 问卷 Q&A/截止日/负责人/状态。
- **操作**：材料勾选保存（`edd_review`）、审核通过/驳回（`edd_approve`，驳回必填理由）。
- **状态流转**：材料收集中 → 审核中 → 已通过 / 已驳回。
- **权限**：材料=风控专员/审核员/主管；结论=审核员/主管/负责人/管理员。

### 2.5 名单筛查管理 risk-screening.html
- **用途**：筛查记录、命中复核、名单库管理。
- **字段**：批次号/时间/类型（实时·定时批量·手动）/范围/命中数/状态；命中记录（对象/名单/匹配度/说明/状态）。
- **操作**：立即批量筛查、误报标记、确认命中（`screen_mark`）；名单库启停（`list_manage` = 合规负责人/管理员）。
- **名单库**：OFAC SDN、UN、EU Consolidated、PEP 库、自定义风险名单。
- **状态流转**：待复核 → 误报 / 确认命中（确认后自动生成告警）。

### 2.6 交易风控告警中心 risk-alerts.html
- **用途**：告警队列 + 规则展示 + 工单流转。
- **字段**：告警号/时间/商户/命中规则/金额/等级/状态/负责人；详情含关联交易、说明。
- **筛选**：状态、等级。
- **操作**：分配（`alert_assign`）、开始调查、结论（放行/加强监控）、转账户管控、生成 STR 草稿。
- **状态流转**：新告警 → 调查中 → 待审批 → 已结论。
- **权限**：处理=风控专员/主管；分配=主管/管理员。

### 2.7 商户风险台账 risk-ledger.html
- **用途**：风险等级档案 + 复审计划 + 历史记录。
- **字段**：商户/当前等级/评分/复审到期（临期标红）/管控状态/风险标签/入网日期。
- **操作**：时间线弹窗（该商户全部审核与管控记录，来自审计日志）。
- **权限**：全角色可见。

### 2.8 账户管控中心 risk-controls.html
- **用途**：限制/冻结的申请、审批、解除。
- **字段**：编号/商户/类型（仅入金·禁止出金·暂停账户·冻结资金）/理由/审批流/时间/状态。
- **操作**：新建管控申请（理由必填 → 双人审批 → 生效）、解除管控（理由必填留痕）。
- **状态流转**：生效中 → 已解除（不可删）。
- **权限**：`control_apply/control_lift` = 风控主管/合规负责人/管理员。
- **红线**：禁止自动永久冻结；自动规则仅告警。

### 2.9 STR 可疑交易上报 risk-str.html
- **用途**：STR 草稿、签发、上报、归档。
- **字段**：报告号/对象/标题/监管机构/创建人/状态/上报时间/摘要。
- **操作**：新建草稿（`str_draft`）、签发上报（`str_submit` = 合规负责人/管理员，不可撤回）。
- **状态流转**：草稿 → 已上报 → 已归档。

### 2.10 合规审计日志中心 risk-audit.html
- **用途**：全操作留痕检索与导出。
- **字段**：时间/操作人/角色/操作/对象/详情。
- **筛选**：角色、操作类型、搜索。
- **操作**：导出审计包 CSV（`audit_export`）。
- **特性**：只增不删，无删除接口；留存 ≥ 5 年。

### 2.11 合规配置中心 risk-config.html
- **用途**：复审周期（低 12/中 6/高 3/极高 1 个月）、国家风险等级库、行业风险库、风控阈值、自动规则开关。
- **权限**：`config_edit` = 合规负责人/管理员；其余不可见本页。

## 3. 状态流转定义

| 对象 | 状态机 |
|---|---|
| 商户 KYC | 待提交 → 审核中 → 已通过 ⇄ 复审待办 ⇄ EDD 进行中 → 暂停入网 |
| 风险等级 | 低 → 中 → 高 → 极高（动态重评，可升可降，每次变更留痕） |
| EDD 工单 | 材料收集中 → 审核中 → 已通过 / 已驳回 |
| 告警 | 新告警 → 调查中 → 待审批 → 已结论（放行/加强监控/转管控/转 STR） |
| 账户管控 | 申请 → 主管审批 → 负责人批准 → 生效中 → 已解除 |
| STR | 草稿 → 已上报 → 已归档 |

## 5. 非功能要求
1. 所有审核动作、附件、评论、修改记录不可删除（审计日志只增）。
2. 支持导出 PDF/Excel 审计包，用于监管问询与 EDD 调查回复。
3. 与客户管理、交易模块打通（商户编号 M-xxxx 与交易 TX-xxxx 全局关联）。
4. 区分【自动规则】与【人工复核】：自动规则仅产生告警，管控动作必须人工审批。
5. 禁止自动永久冻结：所有冻结、限制操作必须走审批流。

## 6. 风险规则样例（15 条，已内置可直接配置）

| 编号 | 规则 | 触发条件 | 动作 | 等级 |
|---|---|---|---|---|
| R-01 | 大额交易 | 单笔 > 近 90 天日均交易额 ×20 或 > €50,000 | 告警 | 高 |
| R-02 | 高风险地域交易 | 对手注册地 ∈ 高风险地区库 | 告警 | 极高 |
| R-03 | 新收款方大额首笔 | 首次交易且 > €10,000 | 告警+2FA | 中 |
| R-04 | 快进快出 | 入账 24h 内转出 > 90%，连续 ≥ 3 笔 | 告警 | 高 |
| R-05 | MCC 偏离 | 卡消费类别与申报行业偏离 | 告警 | 中 |
| R-06 | 关联方交易 | 收付双方同 BO / 同地址 / 同设备 | 告警 | 高 |
| R-07 | 拆分交易 | 同日 ≥ 3 笔金额在阈值 90%-99% | 告警 | 中 |
| R-08 | 收款账户涉欺诈 | IBAN 命中反欺诈名单 | 拦截+告警 | 极高 |
| R-09 | 夜间高频交易 | 00:00-05:00 交易占比 > 40% | 告警 | 中 |
| R-10 | PEP/制裁命中 | 商户/BO/对手筛查命中 | 拦截+告警 | 极高 |
| R-11 | 商户信息变更 | 地址/法人/BO/经营范围变更 | 复核 | 中 |
| R-12 | 行为偏离画像 | 月交易模式偏离度 > 60% | 告警 | 中 |
| R-13 | EDD 逾期未补 | 工单超期 5 个工作日 | 告警+建议管控 | 高 |
| R-14 | 复审到期 | 复审到期前 7 天 | 复核提醒 | 低 |
| R-15 | 退款率异常 | 月退款率 > 8% 或环比 ×3 | 告警 | 中 |
